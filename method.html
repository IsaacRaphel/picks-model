What I designed

The daily work is done by AI agents running on scheduled jobs, but they follow a system I designed. The decisions that are mine:

  • The question and scope: test how close a disciplined process gets to the market across the NFL, NBA and power-conference college football and basketball, compared against DraftKings, FanDuel and Kalshi.
  • What to collect: the set of structured features logged for every game (below), chosen so a real model can be fit on them later.
  • How forecasts are built: start from a public rating system, adjust for game context, and never double count what the line already prices in.
  • How results are judged: against-the-spread record, closing line value, calibration and simple-strategy control groups, not just wins and losses.
  • The lessons framework: separating bad luck from real mistakes, turning repeated mistakes into hypotheses, and the statistical tests a hypothesis has to pass.
  • Official plays: the criteria for which games count as the model's real plays.

What's logged for every game

Besides the lines at all three books and the forecast itself, each game stores structured inputs so a model can be fit on them: the rating system used and each team's rating, the line the ratings imply, home advantage and neutral site, rest days and back-to-backs, key players out, quarterback changes, time zones traveled, games played, strength-of-schedule rank, the opening line, the share of public bets on each side, and the closing line. Missing values are stored as blank, never guessed.

How forecasts are made

  • Baseline: start from the line a public rating system implies, so the starting point is consistent and testable.
  • Adjust for context: injuries, rest, travel and situational spots, weighted (injuries and rest count most), with any 2+ point move from the ratings explained in writing.
  • No double counting: home field and well-known injuries are already in the price, so they don't count as an edge on their own.
  • Big disagreements are a warning: if the model is 3+ points off the market, it has to name the specific thing the market is missing, or shrink the edge.
  • Official plays: a game counts only with an edge of at least 1.5 points, no unresolved injury question, no huge spread, and no lesson overriding the model's own number. Usually 2 to 8 a day.

How it's graded

  • Against the spread: the main record. Break-even is 52.4% because a standard bet risks 110 to win 100 (110 / 210 = 52.4%).
  • Closing line value: how many points better the model's number was than the final market number. It's a faster signal of skill than wins and losses.
  • Calibration: whether teams the model gives a 70% chance actually win about 70% of the time.
  • Control groups: the same games picked by simple rules (always the favorite, always the underdog, always home, ratings only). The model has to beat these to be worth anything.

Statistical rules

Uncertainty is always shown. Every win rate comes with a 95% Wilson confidence interval. With about 200 games, that range is roughly ±7 points, so a 53% record could really be anywhere from about 46% to 60%. A record only counts as evidence of an edge once the whole range sits above 52.4%.

Lessons have to pass real tests. Each lesson is a hypothesis tested on the picks it changed. To be kept it needs:

  • at least 50 picks (at 15 picks the uncertainty is about ±25 points, which tells you nothing),
  • a one-sided exact binomial test showing it beats 52.4%,
  • a Benjamini-Hochberg correction at a 10% false discovery rate across all lessons with enough picks, because testing many hypotheses at once guarantees some will look good by chance (the multiple comparisons problem),
  • and an average closing line value of zero or better, so a lesson that wins while getting worse numbers than the market doesn't count.

A lesson is dropped once it has 50+ picks and is below 50%, or 100+ picks without passing. Dropped lessons stay on file so the same idea isn't relearned. Early on, almost nothing should pass; that's the expected result, not a failure.

Out-of-sample testing. Formula v1 is built from the first phase of data and then run on new games without changes, so it can't be tuned to fit the results it's judged on.

Limitations

  • Small samples. Hundreds of games are needed before any record means much; everything here is labeled with its uncertainty for that reason.
  • Automated collection can make mistakes. Lines, ratings and injuries are gathered from public web pages by AI agents. A daily consistency check catches contradictions, but data errors are possible.
  • Closing line is approximate. The 6:30pm ET price stands in for the true closing line, which can still move before tip-off.
  • The model picks every game. That keeps the dataset complete, but it means the all-games record includes many close calls; the official-play record is the fairer test.
  • Markets are efficient. The most likely outcome is that the model can't beat closing prices consistently. The value is in measuring how close it gets and where the market is weakest.
  • No real money. This is a research project. Nothing here is betting advice.
