Top pick of the day

Model = the model's raw line or win chance before any lessons. A purple "Lesson test" tag means a lesson the model is testing changed the pick from what the raw number says, so the pick and the model line can point different ways on those games. Edge = how far the model's number is from the market on the picked side (0 when a lesson made the pick). "Not posted" means that book had no line when the data was collected.

Hypotheses the model is testing

Repeated mistakes become lessons. Each one is tracked on the picks it changed and needs 15+ picks before it's judged: kept if it beats the 52.4% break-even rate, dropped if it doesn't. Rules about what goes into the top pick are measured by how the bets they exclude perform.
